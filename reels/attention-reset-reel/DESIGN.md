# Attention Reset Reel: Design System

## Style Prompt
A cinematic, high-impact social media promotion. The first half is high-tension and dramatic (Shadow Cut style), using fast cuts and glitch effects to represent "hijacked attention." The second half transitions to a premium, focused, and calm aesthetic (Velvet Standard influence) with elegant typography and golden accents.

## Colors
- **Primary Background**: #0E0E0B (Rich Black)
- **Accent 1**: #F5C842 (Attention Gold - for solutions/CTA)
- **Accent 2**: #FF3B3B (Hijacked Red - for problems/tension)
- **Text**: #EDE8DC (Off-white)

## Typography
- **Headlines**: 'DM Serif Display', serif (Bold, cinematic, dramatic)
- **Body/Details**: 'DM Sans', sans-serif (Clean, modern, high-legibility)

## Motion Guidelines
- **Tension Phase (0-6s)**: Rapid cuts, flickering text, scale jumps, red glow.
- **Resolution Phase (6-15s)**: Smooth cinematic fades, elegant tracking reveals, golden light sweeps.
- **Resolution**: 1080x1920 (9:16)
- **Framerate**: 30fps
